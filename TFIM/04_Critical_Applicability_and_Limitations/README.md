# 4 / Critical Applicability and Limitations

| 实验 | 目的 | 简洁结论 |
| --- | --- | --- |
| A1：联合窗口扫描 | 量化残余非线性误差何时可忽略 | 使用诱导密度响应归一化的 1%/5% 容差，给出逐组通过—失败边界 |
| A2：两条临界路径 | 区分固定波长与 q/m=1，区分固定 λ 与固定 λ/m | 固定幅度时误差可随临界逼近显著放大；不存在由二阶阶数单独保证的窗口 |
| A3：弱场余项及数值边界控制 | 解释 C₂ 的质量依赖，排除积分、核表和起点伪影 | 二阶误差与不断增大的系数可同时存在，窗口须直接测量 |
| A4：保留高阶响应与分支反例 | 防止把局部修复误读成精确/全局泛函 | 二阶谐波仍有偏差，多稳定分支仍可能存在 |
| A5：文献 GGA 同场对照 | 比较临界逼近时半局域与非局域修复 | GGA 改善 LDA，但固定幅度下仍留下明显响应误差 |

ερ=RMS(ρNRC-LDA−ρexact)/RMS(ρexact−ρhom)，α=λ max|v|/m，v 零均值且 RMS=1。窗口是已测网格上从小幅度开始的连续通过前缀，不是任意波形或连续域保证。严格临界 m=0 不在本实验内。

固定 L=32、λ=0.001：最大相对误差在 m=0.003 为 0.656%，m=0.001 为 1.288%，m=0.0003 为 2.588%，m=0.0001 为 6.479%。因此 1% 标准下需要比 m=0.001 更远离临界，或同步降低扰动；实际边界只由相邻已测点夹定。

文献 GGA 固定 J_eff=0.35，来源为 [Mao 等（2021），式 (13)](https://doi.org/10.1103/PhysRevB.104.155145)。在上述固定幅度路径上，复用两侧、两波形的 28 个精确解，三种方法按同一诱导密度归一化。下表取各 m 的四组最大相对误差。

| m | LDA (%) | GGA (%) | NRC-LDA (%) |
| --- | --- | --- | --- |
| 0.1 | 67.843 | 23.467 | 0.0855 |
| 0.03 | 123.255 | 52.022 | 0.2208 |
| 0.01 | 183.565 | 80.980 | 0.3713 |
| 0.003 | 269.335 | 113.352 | 0.6561 |
| 0.001 | 329.494 | 149.472 | 1.2879 |
| 0.0003 | 329.163 | 168.468 | 2.5877 |
| 0.0001 | 328.134 | 169.572 | 6.4791 |

GGA 改善了这些外场中的 LDA 结果，但未恢复临界响应。NRC-LDA 显著减小误差；它的剩余误差仍需用下述窗口衡量。这里的百分比衡量外场诱导响应的偏差，不是总密度的百分比。

完整记录见 `data/gga_critical_path.csv`，剖面与求解器记录见 `profiles/gga/fixed_amplitude.json`，比较图见 `figures/09_gga_critical_comparison.png`。28 个 GGA 点的投影梯度均小于 10⁻¹⁴；均匀表加密引起的密度变化/信号最大为 3.31×10⁻⁹，换初值密度差最大为 5.57×10⁻¹⁵。本目录运行 `python run.py --stages gga verify` 可重算全部 GGA 对照；共享配置位于第三部分 `config/gga_control.json`。

主扫描 620 行，阈值边界另加密 217 行，总计 837 行。几何二分使通过—失败幅度比不超过 1.12；不改变泛函或容差。详细边界、右删失标记与不确定点见 `data/applicability_windows.csv`；完整结果见 `data/window_scan.csv`；全部密度见 `profiles/`。两侧与两波形的包络仅适用于本采样集合。

作为保守起点，峰值扰动 ≤0.2m 在本实验的 200 个相应采样点中，最坏相对误差为 0.862%，均低于 1%；这不是对任意波形的保证。不同周期使用相同的无量纲四模权重/相位和波包形状，以隔离尺度效应。

## 统一工作目录

```text
README.md                本部分的目的、结论与运行说明
run.py                   本部分的统一入口，默认只核验已有数据
config/experiment.json   实验配置或保留证据的核验范围
data/                    标量结果、拟合、窗口和汇总表
profiles/                完整密度剖面；历史反例位于 retained/
cache/                   数值核输入、精确解缓存与临时重算目录
figures/                 本部分论文图（PNG/PDF）
logs/                    运行日志、数据核验和独立复现记录
```

在本目录运行 `python run.py` 或 `python run.py --stages verify`；从其他目录运行本目录 `run.py` 的绝对路径也可。使用 `python run.py --help` 查看支持的阶段。

`python run.py --stages scan analyze refine controls verify` 重算临界窗口实验。`tests` 可单独运行共享结构测试，结果归入第二部分；保留的高阶/多分支反例只核验来源哈希。

共用算法在 `../tfim/`，不复制四份。没有对应产物的目录保留说明文件，不填充虚构结果。完整报告和跨项目审计从 TFIM 根目录运行 `python run.py --stages report audit`；该任务日志位于 `TFIM/logs/`。
